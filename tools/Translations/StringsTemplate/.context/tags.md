# Tags

## code-style
**Id:** blk-c65837d10530

A record earns this term when it is about the house style in which the tool's C# source code is written.

## tool-build
**Id:** blk-a081bea85707

A record earns this term when it is about building the tool with dotnet from its project file and the output that build produces.

## command-line
**Id:** blk-b6e3853f40b5

A record earns this term when it is about the arguments and options the tool is started with and how it reads them.

## exit-codes
**Id:** blk-13df582fee61

A record earns this term when it is about the exit code the tool's process ends with and what each value means.

## console-output
**Id:** blk-37bef7f0f2a8

A record earns this term when it is about the lines the tool prints to the console and how they are worded.

## exception-handling
**Id:** blk-77249af6bc8a

A record earns this term when it is about where the tool catches exceptions and what it does once it has caught one.

## assembly-resolution
**Id:** blk-e7bdf8fb34e4

A record earns this term when it is about how the tool finds the game assemblies that a loaded mod DLL references.

## translations
**Id:** blk-c840241f62b8

A record earns this term when it is about translating a mod's player-visible strings and checking its translation files.

## mod-strings
**Id:** blk-011ddfa8329b

A record earns this term when it is about the player-visible text a mod defines in ModStrings and the translations of that text.

## translation-template
**Id:** blk-e22559e88bb9

A record earns this term when it is about the .pot template the tool writes from the mod's strings.

## refused-translation
**Id:** blk-e74adbf7daf1

A record earns this term when it is about the rules by which the game rejects a translation or a whole po file at load.

## mod-options
**Id:** blk-341f67d1df34

A record earns this term when it is about the player-facing settings a mod exposes on its options screen and how the mod reads them.
