# Tags

## code-style
**Id:** blk-d2157523fce0

A record earns this term when it is about the house style in which the tool's C# source code is written.

## tool-build
**Id:** blk-a5348f1d824f

A record earns this term when it is about building the tool with dotnet from its project file and the output that build produces.

## command-line
**Id:** blk-ce5b62d605a7

A record earns this term when it is about the arguments and options the tool is started with and how it reads them.

## exit-codes
**Id:** blk-118ca47ad523

A record earns this term when it is about the exit code the tool's process ends with and what each value means.

## console-output
**Id:** blk-cf6a5657601c

A record earns this term when it is about the lines the tool prints to the console and how they are worded.

## exception-handling
**Id:** blk-9f91735c0732

A record earns this term when it is about where the tool catches exceptions and what it does once it has caught one.

## steam-workshop
**Id:** blk-b2f89a20a6d1

A record earns this term when it is about publishing a mod to its Steam Workshop item or updating that item.

## release-process
**Id:** blk-707b813b0e5b

A record earns this term when it is about cutting a release of a mod, from version bump and tag to the published download.

## legacy-workshop-item
**Id:** blk-3d4c627c311a

A record earns this term when it is about the legacy ISteamRemoteStorage single-file items that are the only Workshop items the game can download.

## steam-app-id
**Id:** blk-ee5e791bfcda

A record earns this term when it is about the Steam app ids the tool runs under and the steam_appid.txt file that selects one.

## steam-cloud
**Id:** blk-d8b8d8268670

A record earns this term when it is about staging files in the user's Steam Cloud before a publish or update refers to them.

## steamworks-api
**Id:** blk-e03970c61bea

A record earns this term when it is about calling Steam through Steamworks.NET and checking the result of each call.

## workshop-tags
**Id:** blk-9e1b7daa53c3

A record earns this term when it is about the tags a Workshop item carries for the Workshop's browse views.

## item-visibility
**Id:** blk-e4c4603c9bcf

A record earns this term when it is about who can see a Workshop item and how its visibility is set.

## item-description
**Id:** blk-f43cb14a2dd6

A record earns this term when it is about the text shown on a Workshop item's page and in its change history.

## item-download
**Id:** blk-4035aa9cd0e3

A record earns this term when it is about having Steam download a Workshop item and checking what it installed.
